## Quick Start

1. **Read the Assignment**: See [ASSIGNMENT.md](./ASSIGNMENT.md) for complete requirements
2. **Set up your environment**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. **Start building**: Create your solution in this directory
4. **Submit**: Follow the submission instructions in the assignment

## What You'll Build

A distributed system for processing network telemetry data in real-time, performing aggregation, and detecting anomalies.
